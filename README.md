# Data Jobs Dashboard — Power BI Project
![Dashboard Page 1](/images/pow.png)
## 1. Project Introduction

The **Data Jobs Dashboard** is an interactive Power BI project designed to provide insights into the data job market. It helps **aspiring data professionals, data scientists, job seekers, and career switchers** understand salary expectations, job trends, in-demand roles, and other factors that can support informed career decisions.

The project was created to make job-market data easier to explore and understand through interactive visualizations, allowing users to compare roles, examine salary distributions, and discover useful employment trends.

## 2. Skills and Tools Used

**Tool:** Microsoft Power BI Desktop

**Skills demonstrated:**

* Data visualization and dashboard design
* Data analysis and comparison
* KPI cards and salary metrics
* Line, bar, scatter, doughnut, map, and treemap charts
* Interactive filtering using slicers
* Drill-through navigation for detailed job-title analysis
* Salary and job-market trend analysis
* Report layout and visual formatting

## 3. Dashboard Summary

### Page 1: Data Jobs Dashboard — Overview

![Dashboard Page 1](/images/pow.png)

The first page provides a general overview of the data job market. It highlights average and median salaries, median hourly pay, salary ratings, monthly salary trends, and comparisons of earnings across different data-related roles. It also presents job counts and salary information by title, enabling users to identify popular roles and compare their earning potential.

### Page 2: Senior Data Engineer — Drill-Through Analysis

![Dashboard Page 1](/images/pow1.png)

The second page provides a more detailed analysis of the Senior Data Engineer role. It displays yearly and hourly salary metrics, the proportions of jobs offering work-from-home arrangements, degree requirements, and health insurance. It also explores average yearly salaries across countries, job-posting platforms, and the distribution of job types.

Together, the two pages demonstrate how an interactive dashboard can turn job-market data into useful insights for career exploration and decision-making.
