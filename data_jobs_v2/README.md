# Data Jobs Dashboard v2 — Power BI Project
![Dashboard Page 1](/images/ol.png)
## 1. Project Introduction

The **Data Jobs Dashboard 2.0** is an interactive Power BI project designed to provide insights into the data job market. It helps aspiring **data professionals, data scientists, job seekers, and career switchers** explore in-demand skills, compare salaries, and understand the earning potential of different data-related roles.

The dashboard makes job-market data easier to explore through interactive visualizations, allowing users to filter information by job title and country, examine skill demand, and compare salary figures across different roles.

## 2. Skills and Tools Used

**Tool:** Microsoft Power BI Desktop

**Skills demonstrated:**

- 📊 Data visualization and dashboard design
- 📈 Data analysis and comparison
- 🎯 KPI cards for job counts, skill counts, skills per job, and median yearly salary
- 🧮 DAX measures for job counts, job percentage, median yearly salary, and median hourly salary
- 🔀 Field parameters for dynamically switching between job count, job percentage, median yearly salary, and median hourly salary views
- 📊 Horizontal bar charts for comparing in-demand skills and top-paying jobs
- 🎛️ Interactive filtering using slicers
- 🔄 Clear selection button for resetting filter selections
- 🎨 Visual formatting and report layout design
- 💼 Job-market and salary analysis

## 3. Dashboard Summary

### Data Jobs Dashboard 2.0 — Overview

The dashboard provides an overview of the data job market through key performance indicators and comparative visualizations. It displays the total **job count, skill count, skills per job, and median yearly salary**.

The top skills in data chart highlights frequently requested skills, including Python, SQL, AWS, Azure, Tableau, and Spark. This helps users identify technologies that appear frequently in data-related job postings.

The top-paying jobs in data chart compares median yearly salaries across different roles, including Machine Learning Engineer, Senior Data Scientist, Senior Data Engineer, and Software Engineer. This allows users to explore differences in earning potential across job titles.

Interactive slicers allow users to filter the dashboard by job title and country, while the clear selection button makes it easier to reset their selections. The field parameter buttons at the bottom allow users to switch between **job count, job percentage, median yearly salary, and median hourly salary views**.
